# 预测类方法

## 1. 一元/多元线性回归分析

### 核心概念
用线性函数描述自变量与因变量之间的关系，进行预测与影响因素分析。

### 关键公式
一元：
\[
Y = \beta_0 + \beta_1 X + \varepsilon, \quad \varepsilon \sim N(0,\sigma^2)
\]
多元：
\[
Y = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p + \varepsilon
\]
最小二乘估计：
\[
\hat{\boldsymbol{\beta}} = (X^T X)^{-1} X^T y
\]
决定系数：
\[
R^2 = 1 - \frac{SSE}{SST}, \quad \bar{R}^2 = 1 - \frac{SSE/(n-p-1)}{SST/(n-1)}
\]

### 定义
在误差项满足正态、独立、同方差假设下，用最小二乘法估计参数。

### 流程框架
1. 画散点图/相关矩阵，初步判断线性关系
2. 建立模型并估计参数
3. 模型检验（见下）
4. 残差分析
5. 预测与解释系数实际意义
6. 若共线性严重，考虑岭回归或删除变量

### 检验流程
- **整体显著性 F 检验**：
  \[
  H_0: \beta_1=\cdots=\beta_p=0, \quad F = \frac{MSR}{MSE} \sim F(p,n-p-1)
  \]
- **单个系数 t 检验**：\( t = \hat{\beta}_j / se(\hat{\beta}_j) \)
- **拟合优度**：\(R^2\)、调整 \(R^2\)
- **残差诊断**：正态性（Q-Q图）、同方差（残差图）、独立性（DW检验）
- **多重共线性**：VIF \(= 1/(1-R_j^2)\)，VIF>10 视为严重，需处理（删除变量、岭回归、主成分回归）

## 2. 灰色预测（Grey Prediction, GM(1,1)）

### 核心概念
针对“小样本、贫信息”系统，通过累加生成弱化随机性，建立微分方程模型进行预测。

### 关键公式
原始序列 \(x^{(0)}\)，一次累加 \(x^{(1)}\)：
\[
x^{(1)}(k) = \sum_{i=1}^k x^{(0)}(i)
\]
灰微分方程：
\[
\frac{dx^{(1)}}{dt} + a x^{(1)} = b
\]
时间响应：
\[
\hat{x}^{(1)}(k+1) = \left(x^{(0)}(1)-\frac{b}{a}\right)e^{-ak} + \frac{b}{a}
\]
还原：
\[
\hat{x}^{(0)}(k+1) = \hat{x}^{(1)}(k+1) - \hat{x}^{(1)}(k)
\]

### 定义
GM(1,1) 是最常用的单变量一阶灰色模型。

### 流程框架
1. 级比检验（判断是否适合建模）
2. 累加生成
3. 估计参数 a、b（最小二乘）
4. 模型求解与还原
5. 精度检验
6. 预测未来值

### 检验流程
- **级比检验**：\(\sigma(k) \in (e^{-2/(n+1)}, e^{2/(n+1)})\)
- **残差检验**：相对误差 \(\Delta_k = |x^{(0)}(k)-\hat{x}^{(0)}(k)| / x^{(0)}(k)\)，平均相对误差 <0.1 为合格
- **后验差检验**：小误差概率 P、后验差比值 C（C<0.35 为好）
- **关联度检验**

## 3. 时间序列（Time Series）

### 核心概念
根据历史数据的时间顺序规律进行外推预测，常用ARIMA、指数平滑等。

### 关键公式
ARIMA(p,d,q)：
\[
\phi(B)(1-B)^d X_t = \theta(B) \varepsilon_t
\]
其中 B 为滞后算子。

### 定义
平稳序列可用ARMA；非平稳先差分再建模。

### 流程框架
1. 画时序图，判断趋势与季节
2. 平稳性检验（ADF）
3. 定阶（ACF/PACF、AIC/BIC）
4. 参数估计
5. 模型诊断
6. 预测与置信区间

### 检验流程
- **平稳性**：ADF检验 p值 <0.05
- **白噪声检验**：残差 Ljung-Box 检验
- **模型显著性**：参数 t 检验
- **预测精度**：MAE、RMSE、MAPE

## 4. 决策树与随机森林（处理回归和分类）

### 核心概念
- **决策树**：通过递归二分，用树结构进行预测。
- **随机森林**：多棵决策树的Bagging集成，降低方差。

### 关键公式
回归树分割准则（最小化MSE）：
\[
\min \left( \frac{n_L}{n} MSE_L + \frac{n_R}{n} MSE_R \right)
\]
分类树：基尼不纯度或信息增益。

随机森林：Bootstrap采样 + 随机特征子集。

### 定义
回归树叶子输出为样本均值；分类树为多数类。随机森林通过投票/平均得到最终结果。

### 流程框架
1. 数据预处理与特征工程
2. 划分训练/测试集或交叉验证
3. 训练决策树或随机森林（控制深度、树数量）
4. 评估性能
5. 输出特征重要性
6. 预测新样本

### 检验流程
- **回归**：\(R^2\)、RMSE、MAE
- **分类**：准确率、精确率、召回率、F1、AUC、混淆矩阵
- **过拟合检验**：训练误差 vs 测试误差
- **特征重要性稳定性**
- **交叉验证**平均性能与标准差
- 与线性回归等基准模型对比

### 补充：XGBoost（进阶）
梯度提升树，串行纠正残差，目标函数含正则项，精度通常更高。常用早停与学习率调节。
