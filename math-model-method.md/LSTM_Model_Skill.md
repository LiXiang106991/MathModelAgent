## 1. 算法简介

**LSTM（Long Short-Term Memory，长短期记忆网络）** 是一种特殊的循环神经网络（RNN）架构，由 Hochreiter 和 Schmidhuber 于 1997 年提出，旨在解决传统 RNN 在处理长序列数据时出现的**梯度消失（Vanishing Gradient）**和**梯度爆炸（Exploding Gradient）**问题。

LSTM 通过引入**门控机制（Gating Mechanism）**和**细胞状态（Cell State）**，能够学习长期依赖关系，在时序预测、自然语言处理、信号分析等领域表现优异。在数学建模竞赛（如国赛、美赛）中，LSTM 常用于时间序列预测类题目（如交通流量预测、股票价格预测、疫情传播预测、能源消耗预测等）。

## 2. 数学建模中的适用场景

| 场景类型 | 具体案例 | 特征说明 |
|---------|---------|---------|
| **时间序列预测** | 股票价格、气温变化、电力负荷 | 数据具有明显时序相关性 |
| **交通流量预测** | 道路拥堵指数、地铁客流量 | 周期性 + 趋势性 + 随机扰动 |
| **疫情/传播模型** | 传染病感染人数预测 | 非线性增长，长期依赖明显 |
| **工业设备监测** | 设备剩余寿命预测（RUL） | 传感器时序数据，退化趋势 |
| **文本/序列分类** | 情感分析、序列标注 | 离散序列的上下文依赖 |

**使用前提：**
- 数据具有时间序列特性（或可被构造为序列）
- 样本量足够训练深度网络（通常 > 1000 条序列）
- 存在长期依赖关系（相隔较远时间点的数据相互关联）

## 4. 算法全流程详解

### 4.1 传统 RNN 的梯度消失问题

传统 RNN 的隐藏状态更新公式为：

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$

在反向传播时，梯度需要通过时间步连乘：

$$\frac{\partial L}{\partial W} \propto \prod_{k=1}^{t} \frac{\partial h_k}{\partial h_{k-1}} = \prod_{k=1}^{t} W_{hh}^\top \cdot \text{diag}(1 - \tanh^2(\cdot))$$

由于激活函数导数 $\tanh' \in (0,1]$，当序列较长时，多个小于 1 的数相乘导致梯度指数级衰减 → **梯度消失**，模型无法学习长期依赖。

---

### 4.2 LSTM 如何解决梯度消失

LSTM 的核心创新是引入**细胞状态（Cell State, $C_t$）**作为信息传输的"高速公路"，并配合**门控机制**进行信息筛选。

- **细胞状态 $C_t$**：贯穿整个链条的线性传输通道，梯度可沿此路径无损反向传播，避免了梯度消失。
- **门控机制**：通过 sigmoid 函数（输出 0~1）控制信息的保留/遗忘/输出比例。

---

### 4.3 LSTM 三门机制详解

#### （1）遗忘门（Forget Gate）— 决定丢弃什么信息

$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$

- **作用**：读取上一时刻隐藏状态 $h_{t-1}$ 和当前输入 $x_t$，输出 0~1 之间的值。1 表示"完全保留"，0 表示"完全丢弃"。
- **直观理解**：如果模型学到"当前主语变了"，遗忘门会关闭旧主语的性别/单复数信息。

#### （2）输入门（Input Gate）— 决定存储什么新信息

$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$

$$\tilde{C}_t = \tanh(W_C \cdot [h_{t-1}, x_t] + b_C)$$

- **作用**：$i_t$ 决定哪些新信息值得更新；$\tilde{C}_t$ 是候选细胞状态（新信息的候选值）。
- **直观理解**：输入门决定"新看到的词是否包含需要记住的属性"。

#### （3）细胞状态更新

$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$

- **作用**：旧信息按比例遗忘 + 新信息按比例加入。
- **关键**：这是**逐元素相加（+）**而非连乘，梯度可稳定反向传播。

#### （4）输出门（Output Gate）— 决定输出什么

$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$

$$h_t = o_t \odot \tanh(C_t)$$

- **作用**：$o_t$ 控制细胞状态的哪些部分输出到隐藏状态 $h_t$。
- **直观理解**：输出门决定"基于当前记忆，下一步应该关注什么"。

---

### 4.4 LSTM 完整数学公式汇总

| 门/状态 | 公式 |
|--------|------|
| 遗忘门 | $f_t = \sigma(W_f [h_{t-1}, x_t] + b_f)$ |
| 输入门 | $i_t = \sigma(W_i [h_{t-1}, x_t] + b_i)$ |
| 候选状态 | $\tilde{C}_t = \tanh(W_C [h_{t-1}, x_t] + b_C)$ |
| 细胞状态 | $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$ |
| 输出门 | $o_t = \sigma(W_o [h_{t-1}, x_t] + b_o)$ |
| 隐藏状态 | $h_t = o_t \odot \tanh(C_t)$ |

其中：
- $\sigma(\cdot)$：sigmoid 激活函数，$\sigma(x) = \frac{1}{1+e^{-x}}$
- $\tanh(\cdot)$：双曲正切函数，输出范围 $(-1, 1)$
- $\odot$：Hadamard 积（逐元素相乘）
- $[h_{t-1}, x_t]$：向量拼接（concatenation）

## 5. 网络结构设置与调参说明

### 5.1 输入特征维度（Input Dim）

- **定义**：每个时间步输入的特征数量。
- **示例**：若用"前 7 天温度 + 湿度 + 风速"预测明天温度，则输入特征维度 = 3。
- **设置**：`input_shape = (timestep, feature_dim)`

### 5.2 时间步 Timestep（滑动窗口大小）

- **定义**：模型一次看多少个连续时间步的数据。
- **设置原则**：
  - 具有日周期性的数据：timestep ≥ 24（小时级）或 7（天级）
  - 具有周周期性的数据：timestep ≥ 7
  - 一般经验：timestep ∈ [5, 50]，可通过网格搜索优化
- **注意**：timestep 越大，模型能看到的历史越远，但计算量也越大。

### 5.3 LSTM 神经元（隐藏单元数）

- **定义**：LSTM 层中记忆单元的数量，决定模型的表达能力。
- **设置原则**：
  - 小数据集：16, 32, 64
  - 中等数据集：64, 128
  - 大数据集：128, 256, 512
- **技巧**：可堆叠 2~3 层 LSTM（第一层 `return_sequences=True`）

### 5.4 Dropout 防过拟合

- **原理**：训练时随机丢弃一定比例的神经元，强迫网络学习冗余特征，降低对训练数据的过度依赖。
- **设置**：
  - LSTM 层间 Dropout：0.2 ~ 0.5（常用 0.2）
  - 全连接层前 Dropout：0.2 ~ 0.5
- **注意**：Dropout 只在训练时生效，预测时自动关闭。

### 5.5 全连接输出层（Dense / FC）

- **单步预测**：`Dense(1)` — 输出下一时刻的一个值
- **多步预测**：`Dense(n)` — 输出未来 n 个时刻的值
- **激活函数**：回归问题通常不加激活（线性输出）；分类问题用 `softmax` 或 `sigmoid`

### 5.6 损失函数（Loss Function）

| 问题类型 | 推荐损失函数 | 公式 |
|---------|------------|------|
| 回归问题 | **MSE（均方误差）** | $L = \frac{1}{N}\sum(y_i - \hat{y}_i)^2$ |
| 回归（异常值多）| MAE（平均绝对误差）| $L = \frac{1}{N}\sum\|y_i - \hat{y}_i\|$ |
| 回归（百分比误差）| Huber Loss | MSE 与 MAE 的结合 |

- **数学建模推荐**：优先使用 **MSE**，收敛稳定，对异常值有一定惩罚。

### 5.7 优化器选择

| 优化器 | 特点 | 适用场景 |
|-------|------|---------|
| **Adam** | 自适应学习率，收敛快，内存占用适中 | **首选**，绝大多数场景 |
| RMSprop | 适合循环网络，自适应学习率 | RNN/LSTM 备选 |
| SGD + Momentum | 可能需要手动调学习率 | 大数据集、需要精细调参 |
| AdamW | Adam + 权重衰减解耦 | 需要强正则化时 |

- **数学建模推荐**：**Adam**（默认参数 `lr=0.001` 通常效果已很好）

### 5.8 Epoch 与 Batch Size

| 参数 | 说明 | 推荐设置 |
|-----|------|---------|
| **Epoch** | 完整遍历训练集的次数 | 50 ~ 500（配合 Early Stopping）|
| **Batch Size** | 每次参数更新使用的样本数 | 16, 32, 64 |
| **验证比例** | 从训练集划出用于验证的比例 | 0.1 ~ 0.2 |

- **注意**：Batch Size 过小（如 1）→ 噪声大，收敛慢；过大（如 512）→ 内存不足，泛化差。

### 5.9 早停 Early Stopping 防止过拟合

- **原理**：监控验证集损失（val_loss），若连续 `patience` 个 epoch 没有改善，则提前终止训练，并恢复最佳权重。
- **设置**：
  - `monitor='val_loss'`：监控验证损失
  - `patience=10~20`：容忍多少个 epoch 不改善
  - `restore_best_weights=True`：恢复验证损失最小时的权重
- **意义**：避免模型在训练集上过度拟合，保证泛化能力。

## 6. 预测对比图绘制

建模完成后，必须绘制**真实值 vs 预测值**对比图，直观展示模型效果：

### 6.1 单步预测对比图
- 横轴：时间步
- 纵轴：目标变量值
- 曲线：真实值（蓝色实线）、预测值（红色虚线）
- 附加：误差带（±1σ）或残差图

### 6.2 多步预测对比图
- 绘制未来多步的预测曲线与真实曲线对比
- 可用阴影区域表示预测置信区间

### 6.3 残差分析图
- 横轴：预测值；纵轴：残差（真实 - 预测）
- 理想状态：残差随机分布在 0 附近，无明显模式

### 6.4 评价指标

| 指标 | 公式 | 说明 |
|-----|------|------|
| **RMSE** | $\sqrt{\frac{1}{N}\sum(y_i-\hat{y}_i)^2}$ | 均方根误差，与原始数据同量纲 |
| **MAE** | $\frac{1}{N}\sum\|y_i-\hat{y}_i\|$ | 平均绝对误差，鲁棒性强 |
| **MAPE** | $\frac{100\%}{N}\sum\|\frac{y_i-\hat{y}_i}{y_i}\|$ | 平均绝对百分比误差 |
| **R²** | $1 - \frac{\sum(y_i-\hat{y}_i)^2}{\sum(y_i-\bar{y})^2}$ | 决定系数，越接近 1 越好 |

## 7. 与其他相近算法的对比

| 对比维度 | **传统 RNN** | **LSTM** | **GRU** | **ARIMA** | **Transformer** |
|---------|-------------|---------|--------|----------|----------------|
| **长期依赖** | ❌ 差（梯度消失）| ✅ 优秀 | ✅ 良好 | ⚠️ 需差分处理 | ✅ 极优秀（自注意力）|
| **训练速度** | 快 | 较慢 | 较快（门少）| 极快 | 慢（计算量大）|
| **参数量** | 少 | 多 | 中等 | 极少 | 极多 |
| **数据需求** | 中等 | 较大 | 中等 | 小 | 极大 |
| **可解释性** | 低 | 低 | 低 | 高（统计意义）| 低 |
| **序列长度** | 短序列 | 中长序列 | 中长序列 | 短序列 | 长序列 |
| **适用场景** | 简单序列 | **时序预测首选** | LSTM 轻量替代 | 线性趋势序列 | 超长序列/NLP |
| **竞赛推荐度** | ⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐ |

### 选择建议：
- **数学建模竞赛时间序列题**：优先 **LSTM** 或 **GRU**
- 若数据量小、趋势线性：**ARIMA** 作为基准对比
- 若序列极长（>1000步）且计算资源充足：**Transformer**（Informer 等）
- **模型融合**：LSTM + ARIMA 残差修正，或 LSTM + XGBoost 集成
