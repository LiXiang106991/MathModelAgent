# 数学建模国赛常用方法知识库

本技能提供全国大学生数学建模竞赛（CUMCM）高频建模方法的结构化知识，便于快速查阅核心概念、公式、流程与检验。

## 使用指南

- 优化问题优先考虑线性/整数规划，复杂时用启发式（SA、GA、NSGA-II）。
- 预测问题先尝试线性回归或时间序列；非线性强用决策树/随机森林/XGBoost；长序列时序依赖用 LSTM。
- 评价问题常用AHP（主观）、熵权法（客观）、TOPSIS（排序）、灰色关联。
- 指标多且相关性强时，先用 PCA 降维或消除多重共线性，再进入建模。
- 所有模型必须做检验与灵敏度/鲁棒性分析。

## 快速索引

### 优化类
- 线性规划、整数0-1规划、非线性规划
- 最短路、最小费用最大流、旅行商问题（TSP）
- 模拟退火（SA）、遗传算法（GA）、NSGA-II
- 灵敏度分析、鲁棒性分析

### 预测类
- 一元/多元线性回归分析
- 灰色预测（GM(1,1)）
- 时间序列（ARIMA等）
- 决策树 + 随机森林
- XGBoost（梯度提升树，含调参与 SHAP 解释）
- LSTM（长短期记忆网络，长序列时序预测）

### 评价类
- 层次分析法（AHP）
- 熵权法
- TOPSIS
- 灰色关联分析

### 降维与特征类
- 主成分分析（PCA）：降维、综合评价、消除多重共线性

### 综合类
- 模拟仿真、博弈论、排队论、元胞自动机、马尔科夫链
- 详见根目录 [综合类算法说明.md](../综合类算法说明.md)

## 通用建模流程建议

1. 问题分析与假设
2. 模型选择与建立
3. 求解（精确/启发式）
4. 检验（统计检验、残差、交叉验证等）
5. 灵敏度/鲁棒性分析
6. 结果解释与政策建议
