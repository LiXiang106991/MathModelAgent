# 评价类方法

## 1. 层次分析法（Analytic Hierarchy Process, AHP）

### 核心概念
将复杂决策问题分解为目标、准则、方案层次，通过两两比较构建判断矩阵，计算权重并进行一致性检验。

### 关键公式
判断矩阵 \(A = (a_{ij})\)，满足 \(a_{ji} = 1/a_{ij}\)。

权重：最大特征值对应的特征向量归一化。

一致性指标：
\[
CI = \frac{\lambda_{\max} - n}{n-1}, \quad CR = \frac{CI}{RI}
\]
\(CR < 0.1\) 认为一致性可接受。

### 定义
主观赋权方法，适合定性与定量结合的多准则决策。

### 流程框架
1. 建立层次结构模型（目标层、准则层、方案层）
2. 构造两两比较判断矩阵（1-9标度）
3. 计算各层权重（和法、根法或特征根法）
4. 一致性检验
5. 层次总排序，得到方案综合权重
6. 决策

### 检验流程
- **一致性检验**：CR < 0.1，否则调整判断矩阵
- **敏感性分析**：改变判断矩阵元素，观察排序变化
- 多专家判断矩阵的群决策综合

## 2. 熵权法（Entropy Weight Method）

### 核心概念
根据指标数据的变异程度（信息熵）客观确定权重，变异越大，权重越大。

### 关键公式
数据标准化后，计算第 j 个指标的熵：
\[
e_j = -k \sum_{i=1}^{m} p_{ij} \ln p_{ij}, \quad k = 1/\ln m
\]
\[
p_{ij} = \frac{x_{ij}}{\sum_i x_{ij}}
\]
信息效用值 \(d_j = 1 - e_j\)，权重：
\[
w_j = \frac{d_j}{\sum_j d_j}
\]

### 定义
完全客观的赋权方法，依赖数据本身。

### 流程框架
1. 构建评价指标矩阵
2. 正向化/标准化处理（极差法、向量归一化等）
3. 计算各指标熵值
4. 计算权重
5. 加权得到综合得分（可结合TOPSIS）

### 检验流程
- 检查是否有零值或负值（需平移处理）
- 权重是否合理（与实际意义对比）
- 与主观权重（AHP）对比，做组合赋权
- 灵敏度：删除某样本后权重变化

## 3. TOPSIS（Technique for Order Preference by Similarity to Ideal Solution）

### 核心概念
通过计算评价对象与正理想解、负理想解的距离，得到相对贴近度进行排序。

### 关键公式
规范化矩阵后加权，正理想解 \(Z^+\)、负理想解 \(Z^-\)：
\[
D_i^+ = \sqrt{\sum_j (z_{ij} - z_j^+)^2}, \quad D_i^- = \sqrt{\sum_j (z_{ij} - z_j^-)^2}
\]
相对贴近度：
\[
C_i = \frac{D_i^-}{D_i^+ + D_i^-}
\]
\(C_i\) 越大越优。

### 定义
基于距离的多属性决策排序方法。

### 流程框架
1. 构建决策矩阵
2. 正向化处理（成本型转效益型）
3. 标准化（向量归一化常用）
4. 确定权重（AHP、熵权或组合）
5. 计算加权规范化矩阵
6. 确定正负理想解
7. 计算距离与贴近度
8. 排序

### 检验流程
- 正向化与标准化方法的合理性
- 权重变化对排序的灵敏度分析
- 与其它评价方法（灰关联、主成分）结果对比
- 检查是否存在逆序现象
## 4. 灰色关联分析（Grey Relational Analysis, GRA）

### 核心概念
通过计算参考序列与比较序列之间的灰色关联度，衡量它们发展趋势的相似或相近程度。关联度越大，说明该比较序列与参考序列的关系越密切，对应因素的影响越显著，或对应方案越优。

### 关键公式
1. 数据无量纲化处理后，计算关联系数：
\[
\xi_i(k) = \frac{\min_i \min_k |x_0(k) - x_i(k)| + \rho \max_i \max_k |x_0(k) - x_i(k)|}{|x_0(k) - x_i(k)| + \rho \max_i \max_k |x_0(k) - x_i(k)|}
\]
其中 \(\rho\) 为分辨系数，通常取 \(0.5\)。

2. 灰色关联度：
\[
\gamma_i = \frac{1}{n} \sum_{k=1}^{n} \xi_i(k)
\]
（也可采用加权关联度）

### 定义
灰色系统理论中的基本方法，用于小样本、贫信息条件下序列之间关联程度的量化分析，既可用于多指标评价排序，也可用于影响因素分析。

### 流程框架
1. 确定参考序列（母序列，通常取最优指标或系统特征行为序列）和比较序列（子序列）
2. 对原始数据进行无量纲化处理（初值化、均值化或区间化）
3. 计算每个指标（或时刻）的关联系数 \(\xi_i(k)\)
4. 计算各比较序列的灰色关联度 \(\gamma_i\)
5. 按关联度从大到小排序
6. 分析结果并给出结论

### 检验与注意事项
- 分辨系数 \(\rho\) 的灵敏度分析（常用 0.5，可在 0.1~1 范围内测试）
- 不同无量纲化方法对排序结果的影响
- 关联度本身无绝对意义，重点关注相对排序
- 建议与 TOPSIS、熵权法等结果进行对比验证
- 数据中出现零或负值时需先进行平移处理

### 国赛常见用法
- 多指标方案综合评价与排序（可替代或补充 TOPSIS）
- 分析各影响因素对目标变量的影响程度（按关联度排序）
- 与熵权法结合：先用熵权确定指标权重，再计算加权灰色关联度
- 小样本、数据规律不明显时的优选分析方法
---

## 组合使用建议

- AHP（主观） + 熵权法（客观） → 组合权重
- 组合权重 + TOPSIS → 综合排序
- 评价结果常用于后续优化模型的目标权重或约束
