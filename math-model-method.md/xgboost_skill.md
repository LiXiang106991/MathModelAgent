## 一、模型定位

**XGBoost = eXtreme Gradient Boosting（极端梯度提升）**

- **类型**: 集成学习 / Boosting / 决策树串行叠加
- **核心思想**: 每棵树学习前面所有树的残差，逐步修正预测错误
- **优势**: 精度高、速度快、正则化完善、特征重要性可解释
- **适用**: 回归、分类、排序任务，结构化数据首选

## 二、核心原理

### 2.1 基础框架

$$\hat{y}_i = \sum_{t=0}^{K} \eta \cdot w_{q_t(x_i)}^{(t)}$$

- $t=0$: 初始预测值（通常取目标均值）
- $t=1...K$: 每棵树的修正量（学习率缩放后）
- $q_t(x_i)$: 第 $t$ 棵树将样本 $x_i$ 分配到的叶子节点
- $\eta$: 学习率（收缩率，防止过拟合）

### 2.2 目标函数（带正则化）

$$	ext{Obj} = \sum_{i=1}^{n} L(y_i, \hat{y}_i) + \sum_{t=1}^{K} \Omega(f_t)$$

**损失函数** $L$（常用选择）:
| 任务 | 损失函数 | 表达式 |
|------|---------|--------|
| 回归 | 均方误差 (MSE) | $L = rac{1}{2}(y_i - \hat{y}_i)^2$ |
| 回归 | 绝对误差 (MAE) | $L = \|y_i - \hat{y}_i\|$ |
| 二分类 | 对数损失 (Log Loss) | $L = -[y_i \ln(p_i) + (1-y_i)\ln(1-p_i)]$ |
| 多分类 | Softmax | 交叉熵 |

**正则化项** $\Omega$（控制模型复杂度）:
$$\Omega(f) = \gamma T + rac{1}{2}\lambda \sum_{j=1}^{T} w_j^2$$
- $T$: 叶子节点数量
- $w_j$: 第 $j$ 个叶子的权重
- $\gamma$: 叶子数惩罚（预剪枝）
- $\lambda$: L2正则化系数

### 2.3 分裂增益计算（贪心算法）

对每个特征、每个候选切分点，计算:

$$	ext{Gain} = rac{1}{2}\left[rac{G_L^2}{H_L+\lambda} + rac{G_R^2}{H_R+\lambda} - rac{(G_L+G_R)^2}{H_L+H_R+\lambda}ight] - \gamma$$

其中:
- $G = \sum g_i = \sum rac{\partial L}{\partial \hat{y}_i}$（一阶梯度和）
- $H = \sum h_i = \sum rac{\partial^2 L}{\partial \hat{y}_i^2}$（二阶梯度和）
- 下标 $L/R$ 表示左/右子节点

**决策规则**: Gain > 0 才分裂，否则停止（预剪枝）

### 2.4 叶子节点最优权重

$$w_j^* = -rac{G_j}{H_j + \lambda}$$

含义: 叶子内样本残差的加权平均，经L2正则化收缩。

## 三、算法流程

```
输入: 训练数据 D = {(x_i, y_i)}, 超参数
输出: K棵树的集合

Step 0: 初始化
  ŷ_i^(0) = mean(y)  或  base_score
  计算初始梯度 g_i, h_i

For t = 1 to K:                    【主循环：逐棵树构建】

  Step 1: 贪心构建第 t 棵回归树
    对每个节点:
      对每个特征:
        对每个候选切分点（排序后相邻值中点）:
          按公式计算 Gain
        选该特征最优切分点
      选全局最优（特征, 切分点）
    递归分裂直到满足停止条件

  Step 2: 计算各叶子最优权重
    w_j = -G_j / (H_j + λ)

  Step 3: 更新预测与残差
    ŷ_i^(t) = ŷ_i^(t-1) + η · w_{q(x_i)}
    重新计算 g_i, h_i

返回: {f_1, f_2, ..., f_K}
```

## 四、关键超参数

### 4.1 核心参数速查

| 参数 | 类型 | 作用 | 推荐值 | 调参优先级 |
|------|------|------|--------|-----------|
| `n_estimators` | 树数量 | 模型复杂度 | 100-1000 | ⭐⭐⭐ |
| `learning_rate` | 学习率 | 收缩率，防过拟合 | 0.01-0.3 | ⭐⭐⭐ |
| `max_depth` | 树深度 | 单棵树复杂度 | 3-10 | ⭐⭐⭐ |
| `min_child_weight` | 最小子节点权重 | 控制分裂保守程度 | 1-10 | ⭐⭐ |
| `subsample` | 样本采样比 | 行采样，增加随机性 | 0.6-1.0 | ⭐⭐ |
| `colsample_bytree` | 特征采样比 | 列采样，增加随机性 | 0.6-1.0 | ⭐⭐ |
| `reg_lambda` | L2正则化 | 权重收缩 | 0.1-10 | ⭐⭐ |
| `reg_alpha` | L1正则化 | 稀疏化 | 0-1 | ⭐ |
| `gamma` | 分裂最小增益 | 预剪枝强度 | 0-5 | ⭐⭐ |
| `scale_pos_weight` | 正负样本权重比 | 处理类别不平衡 | sum(neg)/sum(pos) | ⭐⭐ |

### 4.2 调参策略

**Step 1: 确定基础框架**
- `learning_rate=0.1`, `n_estimators=500`
- 用 `early_stopping_rounds=50` 找最优树数量

**Step 2: 优化单棵树**
- 固定学习率，调 `max_depth` (3→6→8→10)
- 调 `min_child_weight` (1→3→5→10)

**Step 3: 添加正则化**
- 调 `subsample`, `colsample_bytree` (从1.0降到0.8/0.6)
- 调 `reg_lambda`, `gamma`

**Step 4: 降低学习率**
- `learning_rate` 减半，`n_estimators` 翻倍
- 例如: 0.1→0.05→0.01，对应500→1000→5000

## 五、国赛应用场景

| 题型 | 应用方式 | 论文写作要点 |
|------|---------|-------------|
| **预测类** | 主力预测模型 | 给出RMSE/MAE/MAPE，与ARIMA/LSTM对比 |
| **评价类** | 特征重要性辅助赋权 | 用`plot_importance`输出关键指标排序 |
| **分类问题** | 二分类/多分类基线 | 给出Accuracy/F1/AUC，与SVM/RF对比 |
| **特征工程** | 提取Top-K重要特征 | 简化后续模型输入，体现降维思想 |

### 5.1 论文中应包含的内容

1. **模型原理**: 简述GBDT框架 + XGBoost的三项改进（二阶导数、正则化、并行优化）
2. **参数设置**: 表格列出关键参数及选取依据
3. **特征重要性**: 柱状图展示Top-10特征
4. **模型评价**: 
   - 训练集/测试集误差对比（防过拟合）
   - 与基线模型（如线性回归、随机森林）对比
   - K折交叉验证结果
5. **灵敏度分析**: 改变`max_depth`或`n_estimators`观察性能变化

## 六、常见问题与对策

| 问题 | 现象 | 解决方案 |
|------|------|---------|
| 过拟合 | 训练集误差远小于测试集 | 降低`max_depth`，增大`reg_lambda`，降低`learning_rate` |
| 欠拟合 | 训练/测试误差都大 | 增加`n_estimators`，提高`max_depth`，提高`learning_rate` |
| 类别不平衡 | 少数类召回率低 | 设置`scale_pos_weight`，或用`focal_loss` |
| 特征重要性虚高 | 高基数类别特征排名异常 | 用`gain`替代`weight`作为重要性度量 |
| 内存溢出 | 大数据集训练失败 | 使用`DMatrix` + 外部存储，或换LightGBM |

## 七、与其他模型对比

| 维度 | XGBoost | LightGBM | CatBoost | Random Forest |
|------|---------|----------|----------|---------------|
| 分裂策略 | Level-wise | Leaf-wise | Oblivious | 随机特征子集 |
| 训练速度 | 中等 | **最快** | 中等 | 快 |
| 内存占用 | 较大 | **较小** | 中等 | 大 |
| 类别特征 | 需编码 | 需编码 | **原生支持** | 需编码 |
| 缺失值 | **自动处理** | 自动处理 | 自动处理 | 需填充 |
| 过拟合控制 | **强** | 中等 | 强 | 中等 |
| 并行能力 | 特征+数据并行 | 特征+数据+投票 | 数据并行 | 天然并行 |
| 精度 | **高** | 高 | **高** | 中等 |

**选型建议**:
- 数据量 < 10万，追求精度 → **XGBoost**
- 数据量 > 100万，追求速度 → **LightGBM**
- 大量类别特征，不想编码 → **CatBoost**
- 需要快速基线，防过拟合 → **Random Forest**
